🧩 挑战你的大脑极限！15个关卡，难度逐级提升，多种谜题类型等你破解。

## 游戏特点

- ✅ 15个精心设计的关卡
- ✅ 多种谜题类型：数列、密码、逻辑、哈希、二进制、等
- ✅ 三段式提示系统
- ✅ 自动保存进度
- ✅ 关卡选择功能

## 安装

### 前置要求
- Python 3.7+
- pycryptodome 库（用于解密第15关）

```bash
pip install pycryptodome
```

### 运行游戏

```bash
cd puzzle_game
python main.py
```

## 操作说明

- 输入 `hint` 获取提示
- 输入 `skip` 跳过当前关卡
- 每关有3次尝试机会

## 进度保存

游戏进度会自动保存在 `progress.json` 文件中，下次启动时会自动加载。

## 重置进度

在主菜单选择"4. 重置进度"可以清空所有游戏记录。
